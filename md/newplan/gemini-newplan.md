# AI 트레이딩 시스템 통합 계획안 (Gemini Synthesized Plan)

## 1. 기획 목표 및 핵심 설계 원칙

### 1.1. 기획 목표

대한민국(KRX) 및 미국(NYSE/NASDAQ) 주식 시장의 실시간 데이터를 기반으로, 신뢰성과 안정성을 최우선으로 확보한 AI 트레이딩 시스템을 구축한다. 초기에는 수익성보다 리스크 통제와 설명 가능한 의사결정 체계 확립에 집중하며, 점진적으로 시스템을 고도화하고 자동화 수준을 높인다.

### 1.2. 핵심 설계 원칙

본 계획안은 `Claude`, `GPT`, `Codex`의 계획안에서 도출된 최상의 원칙들을 통합한다.

1.  **정교하고 확장 가능한 아키텍처 (From Claude):** 시스템의 각 구성요소를 명확히 분리하고, 메시지 큐를 중심으로 한 이벤트 기반 아키텍처를 채택하여 확장성과 유지보수성을 극대화한다.
2.  **데이터 무결성 및 리스크 관리 우선 (From GPT):** 금융 데이터의 특성(시점, 중복, 결측)을 정확히 이해하고 처리하며, AI의 판단을 최종적으로 검증하는 독립적인 `리스크 게이트(Risk Gate)`를 시스템의 핵심 안전장치로 설계한다.
3.  **측정 가능하고 실용적인 실행 계획 (From Codex):** 전체 프로젝트를 명확한 성공 기준이 있는 작은 단계(Phase)로 나누어, 실패 비용을 최소화하고 점진적으로 성공을 구축하는 애자일 방식으로 접근한다.
4.  **설명 가능한 의사결정 (From All):** 모든 매매 판단의 근거가 되는 데이터, 모델 버전, 신호 값, 리스크 통과 여부를 상세히 기록하여, 모든 거래를 사후에 감사하고 분석할 수 있도록 보장한다.

## 3. 데이터 및 AI 모델 설계

### 3.1. 데이터 스키마 원칙 (GPT)

- 모든 이벤트는 `event_id (멱등 키)`, `published_at_utc`, `ingested_at_utc` 필드를 필수로 포함한다.
- 뉴스 데이터는 `novelty_score(새로움)`, `reliability_score(신뢰도)`를 포함하여 품질을 정량화한다.
- 시세 데이터는 결측 구간을 명시적으로 표기하고, 추정값으로 채우지 않는다.

### 3.2. AI 에이전트 설계 (GPT/Codex)

- **Agent A (이벤트 분석):** 뉴스/공시 텍스트를 입력받아 `이벤트 타입`, `감성 점수`, `영향력 등급`을 출력하는 NLP 모델.
- **Agent B (시장 분석):** 시계열 데이터를 기반으로 현재 시장의 `추세(상승/하락/횡보)`, `변동성(안정/과열)`, `유동성(풍부/부족)` 상태를 판별하는 모델.
- **Agent C (신호 융합 및 규모 결정):** Agent A와 B의 출력을 종합하여 최종 `매수/매도 점수`를 계산하고(LightGBM 활용), GPT의 제안처럼 `(기본 예산 * 신뢰도 * 유동성) / 변동성` 공식에 기반하여 포지션 크기를 결정한다.

## 4. 리스크 관리 및 실행

### 4.1. 독립적 리스크 게이트 (GPT)

AI 에이전트가 생성한 '제안 주문'은 실행 계층으로 바로 전달되지 않고, 반드시 독립된 리스크 게이트를 통과해야 한다. 리스크 게이트는 다음과 같은 규칙을 순차적으로 검증하며, 하나라도 위반 시 주문을 차단하고 `RISK_BLOCK` 로그를 남긴다.

- **하드 리밋:** 종목당 최대 투자 비중, 계좌 총 손실 한도, 섹터별 노출 한도.
- **동적 리밋:** 현재 시장 변동성, 호가 스프레드, 슬리피지가 사전 정의된 임계치를 초과하는가?
- **상태 리밋:** 해당 종목이 거래 정지, 투자 경고, 블랙리스트 상태인가?

### 4.2. 설명 가능한 로그 (Codex)

모든 주문 제안 및 최종 실행에 대해 다음을 포함하는 `Decision Log`를 생성한다.
`{decision_id, timestamp, symbol, model_version, input_features_hash, agent_scores, risk_gate_result, final_action, reason_code}`

## 5. 단계별 실행 계획 (Codex)

### Phase 1: 신뢰 가능한 데이터 기반 구축 (4~6주)

- **범위:** 데이터 수집/정규화/저장 파이프라인 완성. GPT가 제안한 데이터 스키마 적용. 중복 뉴스 제거 로직 구현.
- **성공 기준:**
    - 이벤트 수집-처리 지연 시간(p95) 5초 미만 달성.
    - 뉴스 기사 중복 탐지 정확도 99% 이상.
    - 2주 이상 무중단 데이터 수집 및 기록.

### Phase 2: AI 신호 개발 및 백테스팅 (8~12주)

- **범위:** `Agent A`, `Agent B` 초기 모델 개발. GPT가 강조한 `Look-ahead bias`가 제거된 정교한 백테스팅 프레임워크 구축.
- **성공 기준:**
    - Walk-forward 백테스트에서 벤치마크(e.g., KOSPI) 대비 우수한 위험 조정 수익률(Sharpe Ratio) 기록.
    - 주요 파라미터에 대한 민감도 분석 리포트 완료.

### Phase 3: 리스크 게이트 연동 및 모의/소액 거래 (12주+)

- **범위:** `Risk Gate`와 `Execution Layer` 구현. 증권사 모의투자 API 연동. 최종 의사결정 로그 시스템 완성.
- **성공 기준:**
    - 1개월간 모의거래에서 리스크 한도 위반 사례 0건.
    - 모든 거래에 대해 `Decision Log` 100% 생성 및 재현 가능.
    - 사전 정의된 소액으로 실거래를 시작하고, 운영 안정성 검증.

## 6. 결론

본 통합 계획안은 **Claude의 정교한 아키텍처** 위에 **GPT의 데이터/리스크 처리 지혜**를 담고, 이것을 **Codex의 현실적인 실행 로드맵**에 따라 구축하는 것을 목표로 한다. 이 접근법은 초기 단계의 복잡성과 리스크를 최소화하는 동시에, 장기적으로는 전문가 수준의 확장성 있고 안정적인 AI 트레이딩 시스템으로 발전할 수 있는 가장 균형 잡힌 경로를 제공한다.
