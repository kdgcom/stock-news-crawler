# 00. 프로젝트 전체 개요

## 목표

한국(KRX) + 미국(NYSE/NASDAQ) 주식 시장의 뉴스/시세 데이터를 실시간 수집하여,
AI 분석 기반으로 매수/매도/관망 신호를 생성하는 투자 의사결정 시스템을 구축한다.

## 3대 원칙

1. **데이터 품질 > 모델 정확도 > 수익 최적화**
2. **장애 시 기본값 = "no new position"**
3. **모든 의사결정은 재현 가능한 로그로 남긴다**

## 기술 스택

| 역할 | 기술 | 비용 |

| 서버리스 컴퓨팅 | GCP Cloud Run | $0 (무료 한도 내) |

| 언어 | Python 3.11+ | — |
| 모니터링 | Prometheus + Grafana Cloud | $0 |

**MVP 월 비용: $0**

## Hybrid Update (2026-02-16)

### 의사결정 엔진 전환 원칙
- 기본 모드는 `수치 기반 엔진`을 유지한다.
- 고난도 구간(임계값 근접, 이벤트 충돌, 고영향 뉴스)에서만 `Agent Overlay`를 호출한다.
- 최종 점수는 `final_score = alpha * numeric_score + (1-alpha) * agent_score`로 계산한다.
- 기본 `alpha = 0.7`, 변동성 급등/뉴스 급증 구간은 `alpha`를 자동 하향(0.4~0.6)한다.

### 보유종목 기반 매도 제안 기능 추가
- 사용자가 직접 보유 종목/평단/수량/매수일을 입력할 수 있는 웹 페이지를 Cloud Functions로 제공한다.
- 시스템은 보유 포지션 기준으로 `SELL/HOLD/REDUCE` 제안을 생성한다.
- 자동 매도는 하지 않으며, 제안과 근거만 제공하고 사용자 확인 후 실행한다.
## Trade Ledger Update (2026-02-16)
- 거래 원장은 매수/매도 모두 이벤트 단위로 기록한다.
- 보유 수량(`net_quantity`)은 원장 누적값으로 계산한다.
- 매도 제안은 `net_quantity > 0`인 현재 보유 종목에만 생성한다.
